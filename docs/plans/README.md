# Plany implementacyjne

Większe Issue może mieć plan w `active/`. Plan zawiera kontekst, kroki, ryzyka, migrację i strategię testów. Po merge plan jest przenoszony do `completed/` z linkiem do Issue i PR.

Małe, jednoznaczne zadanie nie wymaga osobnego pliku, jeżeli komplet informacji mieści się w Issue.
