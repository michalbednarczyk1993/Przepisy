# Architecture Decision Records

ADR zapisuje decyzję, której zmiana wpływa na architekturę, dane lub sposób rozwoju. Zaakceptowanego ADR nie nadpisujemy tak, jakby wcześniejsza decyzja nie istniała; tworzymy nowy ADR, który go zastępuje.

## Statusy

- `Proposed`
- `Accepted`
- `Rejected`
- `Superseded by ADR-NNNN`

## Szablon

```markdown
# ADR-NNNN: Tytuł

- Status: Proposed
- Data: YYYY-MM-DD
- Decydenci: właściciel produktu + AI Architect

## Kontekst

## Rozważane opcje

## Decyzja

## Konsekwencje

## Powiązane Issues
```
